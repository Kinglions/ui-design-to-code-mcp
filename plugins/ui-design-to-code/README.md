# UI Design to Code

Codex plugin wrapper for `ui-design-to-code-mcp`.

The plugin registers the `ui_design_to_code` MCP server in Codex with:

```bash
npx -y ui-design-to-code-mcp@latest serve
```

Use it when a Codex workflow needs a traceable artifact pipeline for UI
screenshots, Figma node data, target layout IR, code generation records, asset
slicing, and visual review evidence.
